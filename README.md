# A656 FullStack - תרגילי JavaScript: משתנים, תנאים ולולאות

10 משימות. כל משימה נמצאת ב-branch משלה (`task-01` עד `task-10`), עם טסטים משלה.
עוברים למשימה הבאה רק אחרי שהטסטים של המשימה הנוכחית עוברים.

## התקנה (פעם אחת)

צריך Node.js (גרסה 18 ומעלה) ו-git.

```
git clone <כתובת הריפו>
cd <שם התיקייה>
```

אין צורך ב-`npm install`, הטסטים משתמשים רק ב-Node.

## איך עובדים על משימה

1. עוברים ל-branch של המשימה:
   ```
   git switch task-01
   ```
2. פותחים את `main.js`, קוראים את המשימה (ההערה בראש הקובץ) וכותבים את הפתרון **מתחת** לשורה `// write your code below this line`.
3. מריצים את הטסטים:
   ```
   npm test
   ```
4. אם יש כשל, ההודעה אומרת מה היה צפוי ומה הודפס. מתקנים ומריצים שוב.
5. כשהכול ירוק, שומרים (commit) ועוברים למשימה הבאה:
   ```
   git add main.js
   git commit -m "task 1 done"
   git switch task-02
   ```

חוזרים על התהליך עד `task-10`.

## כללים חשובים

- השורות שמסתיימות ב-`// INPUT` (למשל `let number = 58423; // INPUT`) חייבות להישאר. הטסטים מחליפים בהן את הערך כדי לנסות מספרים אחרים, לכן הפתרון צריך לעבוד לכל מספר ולא רק לדוגמה.
- מדפיסים עם `console.log`.
- אל תערכו את התיקייה `tests`.
- לא עובדים על `main` ולא מעבירים שינויים בין ה-branches. כל משימה נפתרת ב-branch שלה.
- הטסטים מסתיימים אחרי 2 שניות, כך שלולאה אינסופית תיכשל עם הודעה.
